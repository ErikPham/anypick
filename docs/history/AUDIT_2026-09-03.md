## Session notes 2026-09-04 (stable proxy token — P0, fixed)

Symptom: Claude Code 401-loops (`POST /v1/messages → 401`) after ANY proxy
restart; only a fresh `use` activation healed it until the next restart.
Root cause: per-instance bearer rotated on every start while client settings
are written once at activation — no refresh path existed anywhere.
Fix: token is now stable per account, persisted in `proxy_state`
(`store.ReleaseProxyRuntimeContext` drops liveness+leases but keeps the
token; `startLocked` reuses it, minting only on first start; abort drops a
freshly-minted token but preserves a reused one). Stop paths, abort paths,
and account deletion (row removed with the account) all verified by tests
(`TestProxyTokenStableAcrossRestart`, updated stale-stop + failed-start
contracts). Live-verified: token identical across stop/start cycles and
equal to the settings value; Claude-style streaming request 200 with the
settings token. One manual step per existing user: rewrite settings once
with the current token (activation does this going forward).

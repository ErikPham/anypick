<Aside type="caution" title="Release channels">
The GitHub Release is the canonical source for signed native artifacts. The CLI
is published there as checksum-listed archives, and through the thin npm
launcher when that channel is enabled (`npm install --global anypick`). The
native macOS, Linux and Windows assets are linked from the latest release. Build
from this repository when you are testing unreleased changes.
</Aside>

For the native macOS source target (macOS 14+, Xcode, and Go required):

```bash
open src/macos/AnyPick.xcodeproj
```

Select the shared **AnyPick** scheme and Run. The build bundles the Go service
inside the app; it does not compile Swift or Go when the app launches.

For the current CLI and terminal UI source workflow (Go 1.26+ required):

```bash
make build
./src/go/bin/anypick-dev --help
./src/go/bin/anypick-dev tui
```

AnyPick answers one question for **Claude Code** and **Codex**: which login
should power this app right now? You pick on the native **Apps** screen or in
the terminal UI; AnyPick handles auth snapshots, local proxies, and client
config.

Install the CLI from the checksum-listed archives on the
[latest GitHub Release](https://github.com/outof0/anypick/releases/latest), or
with `npm install --global anypick` (Node 18+ launcher that fetches and verifies
the matching native CLI on first run). GitHub Releases also carries the macOS
app, Linux and Windows desktop installers, and all CLI archives. The macOS app
is not notarized; first-launch instructions are in the [install guide](/docs/getting-started).
From 1.1.0 the npm package replaces the old JavaScript `anypick@1.0.x`. Start
with [Getting started](/docs/getting-started) for the native macOS app and
CLI/TUI flows. The subcommands mirror the same operations for scripts and CI.
